# G41: 【不具合】タイトル行の文字がクイックアクセスのアイコンに重なる / 下段のモデルタブの文字と × が重なる

- 難易度: 易 / 依存: なし / 触るファイル: `crates/omola-gui/src/ui/chrome.rs`, `src/ui/bottom.rs`(または下段タブを描いている所)
- 先に `docs/issues/gui/README.md` を読むこと。

## 不具合の内容(2026-11-09 メンテナ報告、1280 幅)

1. Simulation タブで、タイトル行の `PID_Controller - Modelica.Blocks.Examples.PID_Controller (Read-Only) - [Plot [1*]]` が左のクイックアクセス(新規・開く・保存・Undo・Redo・Simulate・Stop)の**アイコンの下に潜り込み**、`PI◐_Contro◐er` のように読めなくなる。
2. Simulation タブの最下段のモデルタブで、`PID_Controller` の文字の上に閉じる `×` が重なる。

## 原因

1. `chrome.rs` の `title_bar` 系の処理で、タイトルを `(rect.left() + 170.0 + right) / 2.0` を中心に `painter.text` で描いており、文字幅が「アイコンの右端〜`right`」に収まるかを見ていない。Simulation タブでは `right` が「Plot」見出しの左端になるので中心が左に寄り、長いタイトルが左のアイコンに重なる。170 という固定値も実際のアイコン列の幅と一致していない。
2. 下段のモデルタブは、タブ幅を文字幅から計算していない(または × の領域を引いていない)。

## 実装手順

1. クイックアクセスのアイコン列を描いた後の `ui.min_rect().right()`(実際の右端)を使い、タイトルを描ける範囲を `[アイコン右端 + 8, right - 8]` とする。
2. タイトルの文字幅がその範囲を超えるときは、範囲の中央ではなく左寄せにし、末尾を `...` で省略する(`egui::text::LayoutJob` の `wrap.max_rows = 1` と `break_anywhere`、`overflow_character` を使う)。収まるときは範囲の中央に置く。
3. 下段のモデルタブは、タブ幅 = 文字幅 + × の幅 + 余白 にする。上段のモデルタブ(Graphics 等で出るもの)と同じ関数を使えるなら共通化する。

## テスト

- 「描ける範囲と文字幅から、描画位置と省略要否を返す」関数を作ってテスト(収まる → 中央、収まらない → 左寄せ+省略)。
