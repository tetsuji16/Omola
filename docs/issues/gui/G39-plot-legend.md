## 不具合の内容(2026-11-09 メンテナ報告)

PID_Controller で 10 本以上の曲線を 1 つのダイアグラムに出すと:

- 凡例が 1 行に並ぶだけで、**右端を超えた分が見えない**(`inertia2.w`、`der(inertia2.w)` の先が切れる)。
- 曲線の色は `CURVE_COLORS` の **6 色の繰り返し**で、線種も同じため、7 本目以降はどの曲線か区別できない。
- 凡例の線見本が 1px で短く、縮小表示では色が分からない(すべて黒に見える)。

## 実装手順

1. 凡例のレイアウト: `plot_window()` の「Legend above the frame」部分を、幅を超えたら**次の行に折り返す**ようにする。凡例の行数に応じて、プロット枠(`frame`)の上端を下げる(凡例が枠と重ならない)。
2. 線見本: 長さ 26px のまま、太さ 2px にする。
3. 色と線種: 色は現在の 6 色のまま、7〜12 本目は破線、13〜18 本目は点線にする(`egui::Shape::dashed_line` / `dotted_line`)。凡例の見本も同じ線種で描く。
   - 曲線本体の破線描画は、G21 の間引き後の点列に対して行う(性能を落とさない)。
4. 凡例の名前にマウスを乗せたら、その曲線を太く強調する(任意。やるなら PR に書く)。

## テスト

- 凡例の折り返し計算を関数にして(`fn legend_rows(widths: &[f32], available: f32) -> Vec<Range<usize>>` など)テスト。
- `curve_style(index)` が 0..6 は実線、6..12 は破線を返すテスト。
